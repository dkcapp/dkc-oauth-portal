ระบบภายนอกที่ต้องเชื่อมต่อ:
- OAuth Provider Base URL: https://oauth.dhammakaya.network
- ต้องการ Redirect URI / Callback URL — ให้คุณสร้างให้เลย แล้วฉันจะ
  เอาไปแจ้งทีม IT เพื่อลงทะเบียน

  สองระดับ ตามความเหมาะสม
- Client ID / Client Secret: ฉันจะส่งให้ (ใช้ชุดเดียวกันได้ทั้ง OAuth
  Login, ระบบส่งข้อความ, และระบบอนุมัติไปก่อน ถ้า service ไหนใช้
  ไม่ได้ค่อยขอเพิ่ม)

ดีไซน์:

โครงสร้างโปรเจกต์ที่ต้องการ:

- worker/ สำหรับ Backend (index.js, wrangler.toml, .dev.vars)
- .gitignore ที่ครอบคลุม node_modules, .dev.vars, .wrangler, .env
- README.md อธิบาย tech stack และสถาปัตยกรรมของระบบ

สิ่งที่อยากให้ช่วยทำให้ครบวงจร:
1. เขียนโค้ดทั้ง Frontend และ Backend ให้ครบทุกฟีเจอร์ด้านบน
2. รัน npm install ให้ และบอกวิธีรันทดสอบในเครื่อง (localhost)
3. เขียน README อธิบายสถาปัตยกรรมและวิธีใช้งาน
4. ช่วยตั้งค่า git และ push โค้ดขึ้น GitHub (ฉันจะบอกชื่อ organization
   และ repo ตอนถึงขั้นนี้)
5. ช่วยตั้งค่า Cloudflare Workers Builds ให้เชื่อมกับ GitHub repo
   เพื่อ auto-deploy ทุกครั้งที่ push รวมถึงบอกว่าต้องตั้ง Build
   command / Deploy command / Environment Variables อะไรบ้าง
6. หลัง deploy สำเร็จ ช่วยอัปเดต Redirect URI และ APP_URL จาก
   localhost เป็น URL จริงของ production ให้ด้วย
